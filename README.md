# Tree Traversal Java Project

This is a Java Swing GUI project that demonstrates different tree traversal methods: Preorder, Inorder, and Postorder Traversal.

## Features
- **Preorder Traversal**
- **Inorder Traversal**
- **Postorder Traversal**
- GUI interface built with Java Swing

## How to Run
1. Clone the repository to your local machine using the following command:
    ```bash
    git clone https://github.com/Meesaajay/TreeTraversals.git
    ```
2. Open the project in your preferred IDE (e.g., Eclipse).
3. Build the project and run the `TreeTraversalWithGUI.java` class to launch the GUI.
